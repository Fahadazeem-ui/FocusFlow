# FocusFlow v0.3.0

Smart Focus Mode for Windows 11 — boosts the foreground app and throttles everything else.

## Features

- Real-time foreground detection
- Priority boost for the active app
- Background apps → EcoQoS + priority throttle
- Optional network QoS + RAM trim
- Live throttled process list
- In-app whitelist editor
- Start with Windows toggle
- System tray + neon glass UI

## Build

Push to `main` triggers GitHub Actions → downloads `FocusFlow-Setup.exe` artifact.
